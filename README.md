# Coolest Art — make.fun entry

Entry for the make.fun contest **"Make the coolest art"**
(`coolest-art-01`, $250 bounty, closes 13 Nov 2026 17:00 WIB).

The image is a majestic neon koi fish swimming through dark water,
trailing glowing cyan and orange light — dramatic ultra-detailed digital art.

## How it works

`main.py` (Python 3.13, standard library only, no network) copies the
bundled image `entry.png` byte-for-byte to `/output/entry.png`. The run is
fully deterministic: two runs produce identical output bytes.
